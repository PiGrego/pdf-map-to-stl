# PDF Map to STL

Conversione di mappe PDF vettoriali in geometrie validate, output CAD e successivi modelli 3D.

## Baseline

V15 Milestone 5. La baseline deve essere importata e registrata in Git prima di correggere import o logica.

## Cartelle

- `src/pdf_map_to_stl`: codice Python
- `tests`: test pytest
- `config`: configurazione
- `samples`: campioni di prova
- `docs`: handoff, milestone e archivio storico
- `outputs`: risultati generati, esclusi da Git
