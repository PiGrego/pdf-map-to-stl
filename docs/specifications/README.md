# Map specifications

The international specifications the symbol rules refer to (symbol numbers such as 401,
501, 521 in `config/default.toml`):

- `IOF ISOM 2017-2 Revision 6 January 2024.pdf`: International Specification for
  Orienteering Maps, for forest maps.
- `IOF ISSprOM 2019-2 Revision 6 January 2024.pdf`: International Specification for
  Sprint Orienteering Maps, for sprint and urban maps such as the Navile sample.

<https://orienteering.sport/iof/mapping/>, under "International Specification for
Orienteering Maps (ISOM)" and "International Specification for Sprint Orienteering Maps
(ISSprOM)". The IOF is preparing a new revision, ISOM 2030.
